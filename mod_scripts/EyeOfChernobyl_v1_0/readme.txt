mod EyeOfChernobyl v1.00

позволяет следить за всем и всеми =)
добавляет и обновляет отметки на карте о необходмых вам объектах

все настройки правятся в самом начале файла sim_statistic.script:
true = показывать
false = не показывать

show_stalker_spot	- показывать отметки на сталкерах
show_monster_spot	- показывать отметки на монстрах
show_anomalous_spot	- показывать отметки на аномалиях
show_restrictor_spot - показывать отметки на спейс рестрикторах
show_smart_spot		- показывать отметки на смарт террейнах
show_respawn_spot	- показывать отметки на респавнах
